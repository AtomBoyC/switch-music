💡 如何获取 Spotify Developer Client ID & Secret？（支持双向读写歌单）
  1. 访问 Spotify Developer Dashboard 并点击 Create app。
  2. 在 Redirect URIs 中填入：http://127.0.0.1:8765/api/spotify/callback 并保存。
  3. 复制 App Settings 中的 Client ID 和 Client Secret 填入下方，点击授权登录即可拉取私密歌单并支持反向写入 Spotify！
💡 连接自建 Navidrome / Subsonic / OpenSubsonic 音乐服务器（支持双向歌单读写与去重）
  1. 兼容所有支持 Subsonic REST API (v1.16.1) 的自建 NAS 音乐库：Navidrome、Airsonic、Gonic、LMS、Ampache 等。
  2. 支持直接将流媒体歌单匹配同步进您的私有无损音乐库歌单或 ❤️ Starred，也可从私有库反向导出至云平台或 .m3u8。
  3. 采用标准 Subsonic 盐值 MD5 Token 认证，凭据仅以 0600 权限保存在本地 data/subsonic_auth.json。

💡 支持哪些歌单分享链接？（点击查看示例）
  1. 网易云音乐：支持网页链接 https://music.163.com/#/playlist?id=... 或 App 分享文本（含 163cn.tv 短链），自动突破 1000 首曲目上限读取全量歌曲！
  2. QQ音乐：支持 https://y.qq.com/n/ryqq/playlist/... 或手机端分享短链（c6.y.qq.com/base/fcgi-bin/u?...）。
  3. 酷狗音乐：支持网页链接 https://www.kugou.com/songlist/gcid_.../、App 分享短链或 collection_3_..._0 歌单 ID。
  4. 汽水音乐：支持公开歌单分享短链 https://qishui.douyin.com/s/...、App 分享口令或 music.douyin.com/qishui/share/playlist?playlist_id=...。
  5. Apple Music：支持公开歌单 / 专辑链接 https://music.apple.com/cn/playlist/.../pl.... 与 apple.co 短链（自动提取 ISRC 精准匹配）。
  6. YouTube Music：支持公开歌单链接 https://music.youtube.com/playlist?list=PL...。
  7. 若歌单被设为「私密」或「我喜欢的音乐 / Starred」，请点击顶部对应平台卡片登录后在「从已连接账号选择歌单」中拉取。
💡 支持导出/导入哪些本地歌单文件？
  1. 打开 exportify.net 登录 Spotify 即可一键导出任意歌单或 Liked Songs 为 .csv。
  2. 原生支持 M3U / M3U8 (#EXTM3U) 播放列表（可直接从 Jellyfin、Navidrome、foobar2000、MusicBee 拖入导入）。
  3. 同时兼容本工具导出的备份 CSV / JSON、TuneMyMusic / Soundiiz CSV 以及纯文本文件。
