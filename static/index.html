💡 如何用 15 秒获取 YouTube Music 连接信息？（点击展开/收起）
  1. 在浏览器中打开并登录 music.youtube.com，打开右侧开发者工具的 Network (网络) 面板。
  2. 让列表出现请求：直接点击页面上的任意分类标签（例如 Relax、Podcasts），或者清空 Filter 搜索框后按 Cmd + R 刷新页面。
  3. 在右侧 Name 列表中找到任意一条 music.youtube.com 的请求（例如 browse?...、music.youtube.com 或 log_event?...），右键点击它 → Copy → Copy as cURL。
  4. 粘贴到下方输入框并点击「验证并保存连接」即可！（也支持粘贴 cookies.txt 或 Cookie JSON）

💡 如何一键导出 Spotify「我喜欢的音乐 (Liked Songs)」或私密歌单为 CSV？
  1. 打开开源免费的网页工具 exportify.net 并点击 Get Started 登录你的 Spotify。
  2. 你会看到所有的私密歌单以及顶部的 Liked Songs (我喜欢的音乐)，点击右侧 Export 即可下载 .csv 文件。
  3. 将下载的一个或多个 .csv 文件拖入下方区域即可直接解析所有歌曲！

📥 点击选择或将 Spotify CSV 歌单文件拖拽至此

支持 Exportify 导出的单个或多个 .csv 文件（无曲目数量上限）

💡 如何获取 Spotify 开发者 Client ID & Secret？
  1. 访问 Spotify Developer Dashboard 并点击 Create app。
  2. 在 Redirect URIs 中填入：http://127.0.0.1:8765/api/spotify/callback 并保存。
  3. 进入 App 的 Settings，复制 Client ID 和 Client Secret 填入下方。
